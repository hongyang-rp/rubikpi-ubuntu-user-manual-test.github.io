👋 RUBIK Pi 内测指南

感谢您加入 RUBIK Pi 内部测试！本指南将带您了解我们的内部测试（dogfooding）阶段，在此阶段中，您的反馈将帮助我们发现问题，并在产品正式发布前改进 RUBIK Pi。

在本指南中，您将看到以下内容：
如何开始内部测试（Dogfooding）
问题反馈与建议提交流程
支持与资源获取渠道

希望您积极尝试、大胆探索，并随时告诉我们哪些功能好用、哪些地方需要改进。 您的反馈是让 RUBIK Pi 臻至完美的关键！

流程 1：设备预装认证版Ubuntu系统 (9月30日之后)​

📝 首先需要了解​

info
  • 请确保您的设备已预装经过认证的 Ubuntu 系统版本及瑞萨（Renesas）固件。
  • 开始前 - 请完成 🔗设置 步骤。

🏁 准备开始设置！​

1️⃣ 登录及 Wi-Fi 连接​

1: 请在监视器终端（SBC）上登录并修改密码。
2: 配置Wi-Fi网络连接。 🔗 Wi-Fi 连接指南

2️⃣ SSH 连接 (可选)​

1: 获取 RUBIK Pi 3 的 IP 地址。
2: 在您的主机上使用SSH连接到设备。

命令：​
ssh ubuntu@<IP Address>

3️⃣ 安装已构建的包​

在设备上安装预编译软件包。

命令：​
git clone -b ubuntu_setup --single-branch https://github.com/rubikpi-ai/rubikpi-script.git; 
cd rubikpi-script;  
./install_ppa_pkgs.sh

4️⃣ 验证软件版本。​

1: 登录UART控制台/SBC终端/SSH终端，并按照提示重置密码。
账号: ubuntu
密码: ubuntu
2: 在设备终端中运行以下命令验证版本：

命令：​
	cat /etc/os-release

🧭 后续步骤 镜像刷写完成后，参考 运行预置示例应用程序 进行后续步骤。

流程 2 – 用户获取的设备预装 QLI 版本系统（9月30日前）​

📝 首先需要了解​

info
  • 若QLI版本为1.3或更高，请跳过UFS配置更新步骤。
  • 若需在高通网络外访问链接，请创建 qcom 用户账号以下载 UFS 配置工具（用于设置正确的分区和大小）。
  • 开始前 - 请完成 🔗设置 步骤。

🏁 准备开始设置！​

1️⃣ 设置 QDL​

1: 先查阅官方设置指南，以全面了解整个流程。 🔗使用 QDL 工具进行刷写
2: 根据您的主机环境 (Windows/Linux/MAC)，从上述链接下载正确版本的 QDL 工具。

2️⃣ 更新软件 - UFS 配置​

1: 访问链接 🔗 UFS
2: 解压 步骤 1 的包并将文件复制至 UFS 配置文件夹。

3: 将设备切换至 EDL 模式。

4: 运行命令以执行 UFS 配置操作。

命令：​

📌 说明： 此命令适用于 Windows 系统。

<pathToQDL>\QDL.exe prog_firehose_ddr.elf provision_1_3.xml

3️⃣ 更新软件 - Renesas​

1: 下载文件 🔗Renesas FW Update
2: 解压 步骤 1 的包并将文件复制到 Renesas 的目录。
3: 将设备切换至 EDL 模式。

4: 使用 QDL 命令刷写驱动程序。

命令：​

📌 说明： 此命令适用于 Windows 系统。

QDL.exe prog_firehose_ddr.elf rawprogram0.xml rawprogram1.xml rawprogram2.xml rawprogram3.xml rawprogram4.xml rawprogram5.xml patch1.xml patch2.xml patch3.xml patch4.xml patch5.xml

4️⃣ 下载 Canonical 官方 Ubuntu 构建版本​

1: 下载 Tangshan Ubuntu Server 构建包（ZIP） 🔗Canonical 连接 OR [\lab9101\Dropbox\UBUNTU\Rubik-Pi\ ]
2: 解压压缩包

5️⃣ 刷写 Canonical 官方 Ubuntu 镜像​

1: 解压缩 步骤 1 的包并将文件复制到构建目录（canonical/tangshan 文件夹）。 2: 将设备切换至 EDL 模式。 3: 使用以下命令刷写设备：

命令：​

📌 说明： 此命令适用于 Windows 系统。

QDL.exe prog_firehose_ddr.elf rawprogram0.xml rawprogram1.xml rawprogram2.xml rawprogram3.xml rawprogram4.xml rawprogram5.xml rawprogram6.xml patch1.xml patch2.xml patch3.xml patch4.xml patch5.xml patch6.xml

4: 设备将自动启动。

6️⃣ 登录及 Wi-Fi 连接​

1: 在监视器终端（SBC）上登录并修改密码。 2: 配置Wi-Fi网络连接。 🔗 Wi-Fi 连接指南

7️⃣ 安装已构建的包​

在设备上安装已构建的包。

命令：​
git clone -b ubuntu_setup --single-branch https://github.com/rubikpi-ai/rubikpi-script.git; 
cd rubikpi-script;  
./install_ppa_pkgs.sh

8️⃣ 验证软件版本​

1: 登录 UART 控制台/SBC 终端/SSH 终端，并按照提示重置密码。 账号: ubuntu
密码: ubuntu
2: 在设备终端中运行以下命令验证版本：

命令：​
	cat /etc/os-release

🧭 后续步骤 镜像刷写后，参考 运行预置示例应用程序 进行后续步骤。
